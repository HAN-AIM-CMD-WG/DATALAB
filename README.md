# DataLab - HAN AIM CMD

Projecten van het DataLab aan de HAN (Hogeschool van Arnhem en Nijmegen).

## Projecten

| Project | Beschrijving |
|---------|-------------|
| [reachy-mascotte](reachy-mascotte/) | Interactieve robot-mascotte (Reachy Mini) met spraakherkenning, LLM en face tracking |
| [openwebui-src](openwebui-src/) | Private LLM-omgeving (Open WebUI + Ollama) op SURF ResearchCloud voor docenten — RAG, nakijken, toetsen, anonimisatie |
| [anonimiseer](anonimiseer/) | Tooling om documenten (DOCX/PDF/XLSX) en chat-prompts te anonimiseren of pseudonimiseren voor ze naar externe AI-diensten gaan — Electron-app + Open WebUI filter |
