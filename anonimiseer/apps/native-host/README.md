# native-host

Native Messaging host die als brug dient tussen de browser-extensie en de lokale `pii-engine`-sidecar. Wordt meegeleverd met de Electron-app en registreert zichzelf bij installatie in de juiste browser-manifest-directories (Chrome, Edge, Firefox, Brave).
